# Uchechukwu Divine Chukwujeme — Portfolio

A responsive, editorial-style portfolio combining environmental science, technology, field practice, and research communication.

## Preview locally
Open `index.html` in a modern browser. The page is responsive and includes scroll reveals, animated typography, project-art hover effects, and reduced-motion support.

## Current case studies
1. **Egor LGA environmental health practice** — based on the user's SIWES experience at Egor Local Government Secretariat, Uselu.
2. **Student webpage** — front-end learning project. Repository: https://github.com/ucheprecious241-ai/Student-webpage-
3. **Water quality & practical analysis** — academic practical/reporting showcase. Add real measurements and results before publishing.
4. **Research into food security & biotechnology** — seminar/research showcase. Add the final presentation and references if you want visitors to access them.

## Before publishing
- Confirm every case study accurately reflects work you completed.
- Add actual photos, reports, screenshots, outcomes, and project links where appropriate.
- Add LinkedIn if you have a profile you want to share.
- Add a CV PDF if you want a downloadable résumé.
- Check that the email address and GitHub links are correct.
- The site uses Google Fonts; it still falls back to system fonts if fonts cannot load.

## Publish using GitHub Pages
1. Sign in to GitHub and create a new repository, for example `uchechukwu-portfolio`.
2. Upload `index.html` to the repository root (and optionally this README).
3. Open **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish and copy the public URL shown on the Pages settings screen.

Alternatively, import the repository into Vercel and deploy it as a static site. This package does not publish itself; deployment must be authorized from your own account.
